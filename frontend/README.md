# 个人心理档案（PaperCSS 版）

这一版把首页收敛成一张个人档案卡，移除了机器人头像和无关模块，并简化了前台导航。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可。

## 本次调整

- 首页改成 PaperCSS 纸张档案风格
- 移除首页、登录页、管理侧栏和 AI 对话中的机器人头像
- 首页只保留“情绪记录”和“AI 对话”两个主要入口
- 登录与注册合并为居中的档案资料页，切换时带有“收回档案—抽出资料”动画
- 前台导航精简为首页、情绪记录、AI 对话与账号操作
- 管理后台改为文件夹目录与资料纸布局，账号及退出操作移至左侧
- 文章检索、列表、分页改为档案风格
- 文章新增和修改改为独立 Vue 页面，发布、下架及删除集中在修改页
- 咨询会话和情绪日志详情改为独立资料页，不再使用默认弹窗
- 后台确认框统一为纸质档案风格，删除按钮改为深米黄色
- 顶部目录标签可点击返回对应索引，页面日期会自动刷新
- 文章封面缩小、正文编辑区铺满资料页，并移除文章预览功能
- 会话 ID 与用户昵称恢复为普通文字，不再使用灰色圆形头像
- 原有页面、路由和接口逻辑继续保留

## 构建

```bash
npm run build
```
